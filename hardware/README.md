# Mechanical parts

STEP exports of the 3D-printed parts designed in Fusion 360.

| Folder | Parts |
|---|---|
| `cad/component-feeder/` | Tape feeder for SMD components |
| `cad/pcb-holder/` | Modular PCB holder (edges, joining piece, profile connection, clamp) |
| `cad/other/` | Camera holder, component spool holder, limit-switch holder, emergency-button holder |

**Component feeder note:** the feeder is split into two files. Print the main body **only** from `PnP_Component_Feeder_Main_Body.step`. `PnP_Component_Feeder_Parts.step` contains five pieces: its main body is an older version, and the small cube is not needed, so print neither of those two.
